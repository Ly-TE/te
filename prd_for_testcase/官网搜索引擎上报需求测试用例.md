# 官网搜索引擎上报需求测试用例

## 一、需求概述

用户通过搜索引擎进入官网后，需要统计并上报以下当日数据：

1. 当日浏览页面次数（PV）
2. 当日独立访客数（UV）
3. 当日点击下载按钮次数
4. 当日 Web 注册人数

## 二、测试范围

- 搜索引擎来源识别
- PV 数据统计与上报
- UV 数据统计与上报
- 下载按钮点击数据统计与上报
- Web 注册人数统计与上报
- 当日统计口径校验
- 非搜索引擎来源排除校验
- 异常场景与边界场景校验

## 三、前置条件

1. 官网页面可正常访问。
2. 搜索引擎来源识别逻辑已接入，例如来源包含百度、搜狗、360、Google、Bing 等搜索引擎 Referrer。
3. 数据上报接口或埋点服务可正常接收数据。
4. 测试环境可查看上报日志、数据库记录或后台统计结果。
5. 测试账号、注册入口、下载按钮均可正常使用。

## 五、重点校验点

1. 只有搜索引擎来源用户产生的数据才计入该需求统计范围。
2. PV 按页面浏览次数统计，不按用户去重。
3. UV 按当日独立访客统计，同一用户当日只计一次。
4. 下载按钮点击次数按实际点击次数统计，不按用户去重。
5. Web 注册人数只统计成功注册用户，失败或重复注册不计入。
6. 所有指标均按当日自然日维度统计。
7. 上报数据与后台聚合统计结果需要保持一致。
